PUBLIC API ENDPOINTS
================================================================================

All endpoints accept POST with application/x-www-form-urlencoded

✅ /src/api/portal/config.php
   Purpose: Get portal configuration (public data)
   Auth: None
   Response: Portal title, description, colors, branding settings
   
✅ /src/api/portal/catalog.php
   Purpose: Get equipment catalog
   Auth: None
   Parameters: instances_id, category_id (opt), search (opt)
   Response: Asset types with availability count
   
✅ /src/api/portal/availability.php
   Purpose: Check availability & pricing for date range
   Auth: None
   Parameters: instances_id, asset_type_id, start_date, end_date, quantity
   Response: Available count, rental days, pricing breakdown
   
✅ /src/api/portal/inquiry.php
   Purpose: Submit booking inquiry (guest or client)
   Auth: None (portal session optional)
   Guest: guest_name, guest_email, guest_phone, guest_company
   Client: portal_session token
   Response: inquiry_id
   
✅ /src/api/portal/register.php
   Purpose: Register new client
   Auth: None
   Parameters: name, email, password (8+ chars), phone, company
   Response: client_id, session token
   
✅ /src/api/portal/login.php
   Purpose: Login existing client
   Auth: None
   Parameters: email, password
   Response: client_id, name, email, session token
   
✅ /src/api/portal/my_inquiries.php
   Purpose: Get client's inquiry history
   Auth: Portal session required
   Response: List of inquiries for authenticated client

- PRIMARY KEY: id
