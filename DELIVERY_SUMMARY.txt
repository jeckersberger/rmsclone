================================================================================
DATABASE SCHEMA
================================================================================

sustainability_config:
  - PrimaryKey: instances_id (UNIQUE per instance)
  - emission_factors (JSON): vehicle type factors
  - kwh_price_eur (DECIMAL): energy cost per kWh
  - co2_per_kwh (DECIMAL): CO2 grid mix factor
  - enable_client_reports (BOOLEAN)
  - created_at, updated_at (TIMESTAMP)

sustainability_transport_log:
  - PrimaryKey: id (AUTO INCREMENT)
  - tour_id, project_id (INT, nullable)
  - distance_km (DECIMAL): kilometers traveled
  - vehicle_type (VARCHAR): van, truck, car, etc.
  - co2_kg (DECIMAL): calculated CO2 in kg
  - instances_id (INT): multi-tenancy
  - created_at (TIMESTAMP)
  - Indexes: (instances_id, created_at), (project_id, instances_id)

sustainability_energy_log:
  - PrimaryKey: id (AUTO INCREMENT)
  - project_id (INT): related project
  - total_kwh (DECIMAL): total energy consumption
  - co2_kg (DECIMAL): calculated CO2 in kg
  - calculation_basis (TEXT): method documentation
  - instances_id (INT): multi-tenancy
  - created_at (TIMESTAMP)
  - Indexes: (instances_id, created_at), (project_id, instances_id)

sustainability_reports:
  - PrimaryKey: id (AUTO INCREMENT)
  - name (VARCHAR): report title
  - report_type (ENUM): monthly, quarterly, annual, project, client
  - period_start, period_end (DATE): report period
  - data_json (LONGTEXT): report data as JSON
  - pdf_path (VARCHAR, nullable): PDF file location
  - instances_id (INT): multi-tenancy
  - created_by (INT): user who generated
  - created_at (TIMESTAMP)
  - Indexes: (instances_id, report_type, created_at), period dates

================================================================================
API ENDPOINTS REFERENCE
================================================================================

GET /api/sustainability/config.php
  Returns current configuration (emission factors, energy costs)

POST /api/sustainability/config.php
  Updates configuration with provided parameters

GET /api/sustainability/dashboard.php
  Returns KPIs: this month CO2, YoY comparison, split analysis, greenest project

GET /api/sustainability/emissions.php
  Query: period=month&from=2026-03-01&to=2026-03-31
  Returns: total CO2, transport/energy breakdown, project count

GET /api/sustainability/trend.php
  Query: months=12
  Returns: month-by-month CO2 data for charting

GET /api/sustainability/by_project.php
  Query: from=2026-03-01&to=2026-03-31
  Returns: array of projects with CO2 breakdown

GET /api/sustainability/by_client.php
  Query: client_id=5
  Returns: client's total CO2, split, project count

GET /api/sustainability/reports.php
  Returns: list of all generated reports

POST /api/sustainability/reports.php
  Body: {report_type: 'monthly', period_start: '2026-03-01', period_end: '2026-03-31'}
  Returns: newly created report

GET /api/sustainability/report_get.php
  Query: id=123
  Returns: single report with parsed data

GET /api/sustainability/client_report.php
  Query: client_id=5&from=2026-03-01&to=2026-03-31
  Returns: client-facing sustainability report data

PERMISSIONS REQUIRED
================================================================================

Two permission levels must be added to your permission system:

SUSTAINABILITY:VIEW
  - Read access to dashboard, reports, analytics
  - Can view all sustainability data
  - Can view project and client impact

SUSTAINABILITY:CONFIGURE
  - Write access to configuration
  - Can generate new reports
  - Can update emission factors
  - Includes VIEW permission implicitly
